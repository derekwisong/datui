Dataset technical info.

  Tab / Shift+Tab:  On Schema tab: move focus (tab bar ↔ schema table).
                    On other tabs: focus stays on tab bar.
  Left / Right:     On tab bar: switch tabs
  ↑ / ↓:            Schema tab (when focused) or Notes tab: move the cursor
  ? / F1:           Show this help
  Esc / i:          Close info panel

Tabs:
  Schema:     Every column, its type, and which footers the schema came from
  Resources:  What the data costs to hold and to read
  Partitions: The layout of a partitioned dataset. Only when it has one
  Notes:      What datui noticed about the data while reading it. Only when
              there is something to say

Notes:
  A note is an observation, not a fault: a column that is not in every file,
  files that disagree on a type, a file whose footer could not be read. Each
  one says what it is based on, so "in 1 of 3 files" never stands for files
  datui has not looked at. None of them costs a read of its own.

  Each note shows its scope beneath it, and the note the cursor is on shows its
  detail. When the list is taller than the panel, the corner says how many are
  out of view. A note is drawn whole or not at all, so a summary never appears
  without the line saying what it is based on.

  When there is something to note, the i key in the control bar takes a quiet
  accent until this panel has been opened.
