Chart view: tabs for XY, Histogram, Box Plot, KDE, Heatmap.

  Tab / BackTab:    Move focus (tab bar → sidebar fields)
  ← / → (h/l):      On the tab bar: switch chart type
                    On plot style: switch Line / Scatter / Bar
                    On bins/bandwidth: adjust values
  ↑ / ↓ (j/k):      Move selection in the focused column list
  Enter / Space:    Select a column or toggle an option
  + / -:            Adjust bins, bandwidth, or Limit rows when focused
  PgUp / PgDn:      Adjust Limit rows in bigger steps when focused
  Limit rows:       Caps how many rows are used to build the chart
                    (sidebar, bottom)
  e:                Export the chart to PNG or EPS
  ? / F1:           Show this help
  Esc:              Back to the table
