## What's changed

- The home screen reads only what it shows: entering or filtering a directory of 50,000 files reads its names and the rows on screen, not a file per row, and Ctrl+R no longer rescans the cache
- A share or bucket that stops answering reads `not answering` after 30 seconds instead of spinning; Ctrl+R waits on it again
- Holding a key, or keys typed faster than the screen draws, draws once for the lot rather than once a key, so the home screen and the table keep up over a slow SSH link
- A paste goes into the home filter, the `~` path prompt or the focused field in one piece, and a line break in it no longer presses Enter
- datui opens with no row picked and reads nothing until you choose one, so it starts in about two thirds of the memory and a sixth of the threads it did
- A cloud dataset whose files were replaced after it was opened offers to reopen it, keeping the query, filters, sort and drill-down
