Data Quality profiles the current view deliberately. Nothing scans values until you run the visible plan.

Enter: Run the plan, inspect an observation, or open exact matching rows
e: Edit grain, compute budget, comparison and explicit time roles
p: Show the detailed access plan
1 / 2 / 3 / 4: Overview / Columns / Segments / Trends
[ / ]: Choose a column in Segments or Trends
m: Choose the measurement in Segments or Trends
b: Use the highlighted segment as the comparison baseline without rescanning
j / k or Down / Up: Move through fields or results
r: Rerun with a new sample seed
Tab: Move between the result and Analysis tools
Esc: Cancel editing, return one level, or close Analysis
? / F1: Show or hide this help

Every result states how many rows were eligible and evaluated and whether it is exact, sampled, estimated or metadata-only. Temporal meanings are used only after you assign a role to a column.
Sampling selects rows without replacement from a bounded prefix of at most 50,000 rows. It does not cover the entire dataset randomly; sampled segment totals may be unknown.
Complete runs are reused in this session when the dataset, view, plan, seed and time roles still match. The breadcrumb labels a reused run.

Full scans require confirmation. While a plan is running, Esc cancels the result and leaves the source unchanged. File and partition comparisons require an explicit order before "previous" is meaningful.
For exact null, empty, whitespace, non-finite, constant, and category-variant observations, Enter from the detail opens a temporary row view. Esc returns to the same observation. Sampled observations explain when an exact row view needs a full run.
