Export current data to a file.

  Tab / Shift+Tab:  Move focus between fields
  ↑ / ↓ (j/k):      In the format list: change format
                    On Compression: change compression
                    In Path and Delimiter: nothing (no history there, and
                    j/k are characters)
  ← / → (h/l):      Move the cursor in text fields
                    On Compression: change compression
                    On Include header and Source file: move focus
  Space:            Toggle a checkbox (Include header, Source file)
  Enter:            Export, from anywhere in the form. On a blank path the
                    form says "Enter a file path." instead of exporting
  ? / F1:           Show this help (F1 works in text fields)
  Esc:              Close without exporting

  Typing a known extension (.csv, .parquet, .json, .jsonl, .ndjson, .arrow,
  .ipc, .feather, .avro) selects the matching format, and a trailing
  .gz/.zst/.bz2/.xz sets the compression. Picking a format rewrites a typed
  format extension to match, so the name and the bytes agree.

  On a narrow terminal the dialog stacks into one column, Format first;
  ↑/↓ still cycle it.

If the file exists:
  Enter asks first, starting on No. ← / → (h/l) or Tab pick Overwrite or
  No, Enter confirms the one picked, Esc declines. Declining returns to
  the filled form, path intact.

Formats:
  CSV:              Comma-separated values (configurable delimiter, header)
  Parquet:          Columnar format (efficient, compressed)
  JSON:             JSON array format
  NDJSON:           Newline-delimited JSON (one object per line)
  Arrow:            Arrow IPC / Feather v2
  Avro:             Avro row format

  CSV has no lists or structs: those columns are written as JSON text,
  [1,2] or {"x":1}, and the dialog says so when the view has one.
  Parquet, Arrow, JSON and NDJSON keep the real types.

  CSV, JSON and NDJSON write binary as base64 text; the other formats
  keep the bytes.

  Avro writes arrays as lists, categoricals and decimals as strings,
  times and durations as microseconds, and zoned datetimes in UTC.

Source file:
  Only offered for a directory of Parquet files that disagree, local or in
  the cloud. Adds a column
  naming the file each row came from, so a cell that is absent rather than
  null can still be told apart once the data has left datui. No format
  writes "absent", so without it both are written as null. A dataset that
  already has a source_file column keeps it; datui's is added at the end
  under the next free number.

CSV Options:
  Delimiter:        Separates columns: --delimiter when given, else comma.
                    Only the first ASCII character counts, and Tab moves
                    focus, so a tab cannot be typed here — TSV needs
                    --delimiter
  Include header:   Whether to write column names as first row
