Tabbed modal: Sort (column order, sorting) and Filter (row filters).

  Tab / Shift+Tab:  Move focus (tab bar → form → Apply → Cancel → Clear)
  ← / → (h/l):      On the tab bar: switch Sort / Filter
  Ctrl+Enter:       Apply from anywhere in the modal
  ? / F1:           Show this help (F1 works in text fields)
  Esc:              Cancel and close; staged changes are discarded, and
                    reopening shows what is applied

Sort tab:
  (type):           Filter the column list, when the filter field is focused
  Space:            Toggle sort on the highlighted column
  Enter:            Toggle sort on the column and apply at once
  1-9:              Put the column at that place in the sort order
  [ / ]:            Move the column earlier or later in the sort order
  + / - (= / _):    Move the column's display position
  L:                Lock the column to the left edge
  v:                Show or hide the column
  Order:            Ascending or descending

Filter tab:
  Column, Operator, Value and Logic fields; Enter on Add adds the filter.
  Enter on a filter in the list removes it. Clear removes every filter.

Files that disagree:
  Sorting or filtering by a column some files store in another type leaves those
  files' rows out: there is no value in that column to order or compare them by.
  The Notes tab in the Info panel says how many rows those files hold, and
  offers to read the column as text instead, which brings them back — but a
  filter or sort on a column read as text compares text, so `n > 5` then keeps
  "sixty" and drops "10". The Notes tab says so. Clearing the filter or sort
  brings the rows back either way.
