## What's changed

- A delimited format spec takes `[files] path = "{game}_{start:%Y-%m-%d_%H-%M-%S}.csv"`, adding columns read from each file's name, so files opened together say which file each row came from; a dated part with a time reads as a datetime
- Queries take numbers with an exponent, such as `1e9` and `2.5e-3`
- `contrib/formats/mangohud.toml` opens MangoHud frame logs, with each log's game and start as columns
- A folder or glob read through a format spec leaves out the files the spec does not match, such as summaries beside logs, and a note names them
- Chart **Color** takes several columns, a series per combination of their values, and dates and datetimes, named as ISO 8601 to the precision the values need
