## What's changed

- A delimited format spec takes `[files] path = "{game}_{start:%Y-%m-%d_%H-%M-%S}.csv"`, adding columns read from each file's name, so files opened together say which file each row came from; a dated part with a time reads as a datetime
- Queries take numbers with an exponent, such as `1e9` and `2.5e-3`
- Change type makes a column of numbers a duration in the unit they count, and a datetime plus a duration adds in the finer unit, in a query, a derived column or Combine
- Queries read the columns as Change type and Combine left them, and the changes outlive the query
- `contrib/formats/mangohud.toml` opens MangoHud frame logs, with each log's game and start as columns
- A folder or glob read through a format spec leaves out the files the spec does not match, such as summaries beside logs, and a note names them
- Chart **Color** takes several columns, a series per combination of their values, and dates and datetimes, named as ISO 8601 to the precision the values need
- A line or scatter chart takes durations as X and Y, ticked as lengths of time: `250ms`, `30s`, `2m`, `1h30m`
- Durations read in their units, exactly: `16.6667ms`, `1m 23.5s`, `1d 4h`, rather than `16666700ns`; filters and find take them as shown
- A line or scatter chart's **Range** draws outliers at the edge of a Y axis fitted to the rest, so one spike no longer flattens the line
- `o` in Analysis Distribution filters the table to a column's outliers and `O` to the rest, with new `outside` and `between LOW..HIGH` filters
- A line chart's **Smooth** draws a moving average (trailing mean) over a length of time or a number of points, with the raw line behind it
- A line or scatter chart's **Log scale** is a true log10 on Y and, for a number X, on X too: powers of ten evenly spaced, values of 0 or less left out and counted. A log Y used to draw ln(1 + y), so a chart with zeros now leaves them out
