Datui is a terminal UI for tabular data: Parquet, CSV, JSON, Arrow and more,
local or in S3, GCS and HTTP, from a few rows to a few billion.

    - Opens files where they are: local, s3://, gs://, https://, hive-partitioned
    - Home screen: recent datasets, your directories and reachable buckets
    - SQL, a short query language (select a, b where c > 10 by region), fuzzy search
    - Describe, distribution fitting with Q-Q plots, correlation matrix
    - Line, scatter, bar, histogram, box, KDE and heatmap charts; export PNG or EPS
    - Pivot and melt; export CSV, Parquet, JSON, NDJSON, Arrow, Avro; templates
    - Light and dark palettes, every color and default in one config file

Run with no PATH for the home screen. Press ? inside for the keys.
Docs: https://derekwisong.github.io/datui/
