## What's changed

### Home screen

Run `datui` with no path. It lists recent datasets, the current directory,
your configured data directories and the buckets your credentials reach, with
rows, columns and size shown before you open anything. Type to filter by name
or column name; the search also walks below the working directory. Ctrl+O
returns here from anywhere.

### Cloud sources

- Every object store is a row under `CLOUD` on the home screen. Enter lists its
  buckets; the title bar shows where you are.
- `[[cloud.sources]]` adds more stores, with keys read from environment
  variables you name. `s3://<name>@bucket/key` opens from a named
  S3-compatible server, so two servers can share bucket names.
- Bucket lists from the last run show at once, sources are listed side by
  side, and Ctrl+R lists again.
- AWS profiles work: `AWS_PROFILE`, `credential_process`, and SSO or roles
  through the AWS CLI. Every profile that can log in is its own source.
- MinIO client aliases, `MC_HOST_<alias>` and s3cmd's config are sources too,
  with no datui config.
- Azure Blob Storage: after `az login` or `Connect-AzAccount`, every storage
  account you can see is listed, and `abfss://` URLs open. Service principals,
  workload identity, connection strings, keys and SAS tokens work too, and
  `kind = "azure"` sources name one account. An Owner or Contributor with no
  data role reads with the account key, as the Portal does.
- The install script installs into `~/.local/bin` where there is no `sudo`, as
  in Azure Cloud Shell.
- Secrets from elsewhere: `secret_command` (`pass`, `op read`), a Google
  `credentials_file`, and `[cloud] env_files` for a project's `.env`.
  `[cloud] instance_identity = true` uses the VM's own identity on EC2, GCE
  and Azure; Cloud Run and Azure App Service are found without it.
- Public datasets are built in: NOAA weather, Bitcoin and Ethereum, OpenAlex,
  Overture Maps, Google Open Buildings and BigQuery's samples, each with its
  publisher and license. Public buckets open with no login, and a login from
  elsewhere no longer blocks them. `public = true` sources keep your own list.
- Each S3 bucket is read in its own region.
- Cloud folders of partitions or Parquet files are labelled `hive` and `multi`
  and open as one dataset; → goes inside them.
- A remote dataset of many files is counted from its footers and reads only
  the files a page needs: Bitcoin's 1.4 billion transactions open in seconds
  and End reaches the last one. Files whose columns or nested fields changed
  over time read into the newest schema.
- Google Cloud lists every project you can see, each with its buckets, and
  works with only `gcloud auth login`. Each `gcloud` configuration with
  another account is its own source.

### New look

- Default palette after Tokyo Night, dark and light. Every color is still a
  config key.
- Column headers take their column's color; a second header row names each
  type (`D` toggles).
- The current row is tinted with a rail instead of reversed video.
- Keys in the control bar are chips. Nulls are `∅`. Off-screen columns show
  as `+10 →`.

### Remote Parquet

- S3 and GCS objects are read one row group at a time. Paging inside a row
  group makes no requests; the first row group used to be fetched twice on
  open and again on every page.
- The buffer is sized in bytes before it is read, so a wide table stays within
  `max_buffered_mb`.
- A filtered remote table reads a page at a time and takes its row count from
  a short read instead of a second pass.

### Typing while busy

- Keys typed during a load or query are queued and replayed in order instead
  of dropped.
- Ctrl+Q quits from anywhere. Ctrl+C copies in a text field.

### Python

- Works with Python `polars` 1.38 and later, built for 1.43. A plan the wheel
  cannot read, such as a join from 1.44, is refused with a message; passing a
  file path works with any version.
- `datui.view(lf)` now reads Polars' binary plan format. It had been falling
  back to the deprecated JSON format.

### Fixed

- A sidebar filter or sort no longer discards the query you just ran.
- Charts are prepared in the background, so a large chart no longer freezes
  the screen.
- Home after End showed the wrong rows.
- The home screen's bucket list ignored `AWS_ENDPOINT_URL` and
  `--s3-endpoint-url`.
- Nulls sort last in both directions.
- `sidebar_border` and `table_selected` had no effect.
- Quitting during a bucket listing could print a Tokio panic.

### Also

- Built on Polars 0.55.
- Linux arm64 binaries, `.deb` and `.rpm`.
- Building from source needs Rust 1.95.
- Docs rewritten; `--help` and the in-app help brought up to date.
