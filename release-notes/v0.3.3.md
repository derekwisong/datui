## What's changed

This release gives datui a new look. The palette, the chrome and the way the
current row is marked have changed everywhere; the keys have not.

### Changed

- New default colours, dark and light. The dark set is after Tokyo Night with one
  cyan accent; the light set is the same hues darkened for a white background.
  Every slot is still yours to set under `[theme.colors]`.
- The control bar draws each key as a chip.
- Column headers take their column's colour, and a second header row names each
  column's type. `D` toggles the type row; `[display] dtype_row = false` starts
  without it.
- The current row is tinted and carries a rail on the left, instead of being
  drawn in reversed video. `table_selected = "reversed"` brings the old look
  back. The same tint marks the current item in every sidebar and list.
- Nulls are drawn as `∅`, dim, instead of as nothing.
- The header, the row stripe and the control bar are three different shades.
- When columns are off-screen, the header says how many (`+10 →`) instead of
  overwriting the last header's final character with an arrow.
- The home screen opens with the datui wordmark, coloured along the theme's
  gradient; on a terminal shorter than 28 rows the one-line title bar returns.
  Section titles sit on a rule with a count chip, hive and multi-file datasets
  wear a chip, and the current row is tinted with a rail.
- The home screen lists what you opened last, where you are, your cloud buckets,
  your configured directories, and only then the directories derived from
  recents and the desktop's places, which start folded. Folds are remembered
  between runs, and Ctrl+↓ / Ctrl+↑ move between sections. Letters always type
  into the filter: `j`, `k`, `h` and `l` no longer double as keys there.
- The documentation site uses the same palette.
- New colour slots: `accent`, `accent_bright`, `gradient_start`, `gradient_end`.
  The Omarchy template maps them from the theme's accent.

### Fixed

- `sidebar_border` had no effect on the sidebars and the input strip, which read
  a slot the theme never filled. It now does what its name says.
- `table_selected` was parsed and never used.
- Folding every section on the home screen no longer says there are no datasets.
- The demo recordings are re-recorded on a Tokyo Night terminal.
