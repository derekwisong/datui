Navigation:
  Arrows (h/j/k/l): Scroll table
  PgUp/PgDown:     Scroll pages (Ctrl+F / Ctrl+B)
  Home/End:        Go to first/last row (G = End)
  Ctrl+D/Ctrl+U:   Half page down/up
  ::               Go to line number (e.g. :0 Enter for top)
  Enter:           On a grouped row, drill into the group (Esc comes back)

Data Operations:
  /:                Open Query input
  c:                Open charts
  s:                Open Sort & Filter modal (tabs: Sort, Filter)
  a:                Open Statistical Analysis
  p:                Open Pivot & Melt
  e:                Export data to file
  r:                Reverse sort order
  R:                Reset table (clear queries, filters, sorts, locks)
  T:                Apply most relevant template
  t:                Open Template menu

Display:
  i:                Open Info panel (modal: Schema & Resources)
  Tab / Shift+Tab:  In Info: move focus (tab bar ↔ schema table)
  Left / Right:     In Info, on tab bar: switch Schema | Resources
  N:                Toggle row numbers
  F:                Toggle number formatting (thousands separators)
  D:                Toggle the type row under the column headers
  ? / F1:           Open this help (F1 works in text fields). Esc or ? to close.

Help Navigation:
  Arrow keys (↑↓):  Scroll help content
  PageUp/PageDown:  Scroll help pages
  Home/End:         Jump to top/bottom

Analysis View:
  a:                Open statistical analysis
  r:                Resample data (if sampled)
  Arrow keys:       Scroll statistics table
  Esc:              Return to main view

Exit:
  Ctrl+O:           Home screen (works during a load; abandons it)
  Ctrl+Q:           Quit from anywhere (Ctrl+C too, outside a text field)
  q:                Quit

While busy:
  Keys typed at a spinner are queued and replayed once the work is done, so
  typing ahead is never lost. Ctrl+Q/Ctrl+C quit and Ctrl+O abandons a load
  at once.

Empty cells:
  A directory of Parquet files may hold files that disagree, so an empty cell
  says which kind of empty it is:
    null         the data's own null
    absent       the file this row came from has no such column
    conflicting  the file holds the column in another type, so it was not
                 read from that file
  A column whose name is followed by a mark is not in every file, or the
  files disagree on its type. The Info panel's Schema tab says where the
  schema came from.
