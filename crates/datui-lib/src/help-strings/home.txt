The home screen: pick a dataset. datui starts here without a path, and Ctrl+O
returns here from anywhere. Every letter types into the filter, so "json"
finds json; only the keys below are keys.

Navigation:
  ↑ / ↓:            Move the selection (Ctrl+P / Ctrl+N too)
  Ctrl+↑ / Ctrl+↓:  Previous or next section
  PgUp/PgDn:        Move a screenful, stopping at the first and last
  Home / End:       The first or last row
  ← / →:            Fold or unfold a section; → on a directory goes inside it
  Enter:            What the control bar says on this row: "Open all" reads a
                    whole directory as one table, "Inside" steps into it,
                    "Open" loads a file, "Look" finds out first. On a section
                    header, fold or unfold it; on the More row, show the rest;
                    on the hidden-files row, show them
  Space:            While the filter is empty: fold or unfold the section
                    header under the cursor. With a filter typed, it types
  Backspace:        Delete a filter character; on an empty filter, up a
                    level (from a bucket, back to its cloud source)
  Tab:              Cycle the sort; the control bar names the order in effect
  Esc:              Back out one layer: the path prompt, the filter, the
                    directory, then to the open data

Finding:
  (type):           Filter by name or column; fuzzy, so "sal" finds "sales".
                    Typing also searches below the directory you are inside
                    and the listed bucket names; matches appear under "Found"
  ~:                While the filter is empty: type a path or URL by hand.
                    The prompt is a plain editor: characters, Backspace,
                    Ctrl+U clears, Tab completes, Enter opens, Esc closes.
                    With a filter typed, ~ types into it
  Ctrl+U:           Clear the filter or path input
  Ctrl+R:           List again what is on screen
  Ctrl+A:           Show or hide files datui cannot read
  Ctrl+D:           Remember the directory under the cursor, so it stays
                    listed; again to forget it. A file stands for the
                    directory it is in, a heading for the one it lists
  Delete:           Forget the highlighted recent entry, or a whole place
                    after confirming, or a remembered place on its heading,
                    or hide a cloud source
  Shift+Delete:     Forget every recent entry, after confirming

Sections, in order:
  Recent:           Datasets opened before, grouped under the directory each
                    lives in, newest place first
  Current directory: Where datui was launched
  Cloud:            One row per cloud source; Enter lists its buckets
  Configured:       Directories from [data] directories in the config,
                    then those remembered with Ctrl+D
  Elsewhere:        Directories your desktop recorded; starts folded
  Found:            Search results, shown while typing

Reading a row:
  A directory's label says what is directly inside: a count and format
  ("12 parquet"), hive, delta, iceberg, hudi, "mixed", or "dir". A label of
  … has not been looked at yet; labels fill in as you scroll. Inside a
  directory with something openable, the first row is "(all files)" — or
  "(all partitions)" in a hive directory — and Enter there reads the whole
  directory as one table whatever the label says. The row hides while a
  filter is typed, and is absent when nothing inside is openable. Inside a
  directory, the last row counts the files datui can't open; Enter on it
  shows them. The Notes tab says what a read had to decide.

Help and leaving:
  ? / F1:           This help (? before typing starts; F1 always)
  Ctrl+Q / Ctrl+C:  Quit

What datui remembers, all under its cache directory and never the data
itself: recent paths, the shapes and column names it measured (so this
screen can say 1,000 × 11 without reading anything), query history, section
folds, remembered directories, bucket listings, hidden cloud sources and
public places.
datui --clear-cache removes all of it.

Public datasets: Enter opens an HTTP(S) data file or browses an object-store
location. Data stays with its publisher or named mirror until you open it.
