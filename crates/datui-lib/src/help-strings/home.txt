The home screen: pick a dataset. datui starts here without a path, and Ctrl+O
returns here from anywhere. Every letter types into the filter, so "json"
finds json; only the keys below are keys.

Navigation:
  ↑ / ↓:            Move the selection (Ctrl+P / Ctrl+N too)
  Ctrl+↑ / Ctrl+↓:  Previous or next section
  PgUp/PgDn:        Move a screenful, stopping at the first and last
  Home / End:       The first or last row
  ← / →:            Fold or unfold a section; → on a directory, a SQLite
                    database or a file of spec variants goes inside it
  Enter:            What the control bar says on this row: "Open all" reads a
                    whole directory as one table, "Inside" steps into it,
                    "Open" loads a file, "Look" finds out first. On a section
                    header, fold or unfold it; on the More row, show the rest;
                    on the hidden-files row, show them
  Space:            While the filter is empty: fold or unfold the section
                    header under the cursor. With a filter typed, it types
  Backspace:        Delete a filter character; on an empty filter, up a
                    level (from a bucket, back to its cloud source; from
                    the top of a collection's remote dataset, back here)
  Tab:              Cycle the sort; the control bar names the order in effect
                    when it has room
  Esc:              Back out one layer: the path prompt, the filter, the
                    directory (back to the row it was entered from), then
                    to the open table, which the control bar's chip names
  Click:            Select the row; double-click is Enter
  Wheel:            Move the selection three rows, stopping at the ends

Finding:
  (type):           Filter by name or column; fuzzy, so "sal" finds "sales".
                    What you open often ranks first. Typing also searches
                    below the directory you are inside and the listed bucket
                    names; matches appear under "Found"
  ~:                While the filter is empty: type a path or URL by hand.
                    The list shows the directory being typed, narrowed by
                    the name after the last /. The prompt is a plain
                    editor: characters, Backspace, Ctrl+U clears, Tab
                    completes the one name left or what the names share,
                    ↑ / ↓ pick a name, Enter opens a file or goes inside a
                    directory, Esc closes. s3://, gs:// and az://
                    complete from buckets and prefixes already known.
                    With a filter typed, ~ types into it
  Ctrl+U:           Clear the filter or path input
  Ctrl+R:           List again what is on screen
  Ctrl+A:           Show or hide files datui cannot read; inside a SQLite
                    database, its internal tables
  Ctrl+X:           Show the local file under the cursor as bytes, in the
                    hex view, whatever datui would read it as
  Ctrl+D:           Remember the directory under the cursor, so it stays
                    listed; again to forget it. A file stands for the
                    directory it is in, a heading for the one it lists
  Delete:           Forget the highlighted recent entry, or a whole place
                    after confirming, or a remembered place on its heading,
                    or hide a cloud source
  Shift+Delete:     Forget every recent entry, after confirming

Sections, in order:
  Recent:             Datasets opened before, grouped under the directory each
                      lives in, ranked by how often and how lately each was
                      opened; the cursor starts on the one opened last
  Current directory:  Where datui was launched
  Cloud:              One row per cloud source; Enter lists its buckets
  Collections:        Each [[sources]] collection under its label: named
                      datasets, local or remote. Enter opens a file and
                      steps into a directory or a bucket prefix
  Configured:         Directories from [data] directories in the config,
                      then those remembered with Ctrl+D
  Public datasets:    The built-in collection, after your own. Its data stays
                      with the publisher until you open it; a web file under
                      50 MB downloads without a question
  Elsewhere:          Directories your desktop recorded; starts folded
  Found:              Search results, shown while typing

Reading a row:
  Every row reads name, then "/" for a directory, two spaces, and its
  label. A directory's label says what is directly inside: a count and
  format ("12 parquet"), hive, delta, iceberg, hudi, "mixed", "3 dirs" for
  directories only, or "dir" for neither. A label of
  … has not been looked at yet; labels fill in as you scroll. Inside a
  directory with something openable, the first row reads the whole
  directory as one table, and says how: "(hive table: year, month)",
  "(3 Parquet files, one schema)", "(2 Parquet files, schemas differ)",
  "(all files, mixed)" or "(Delta files, not the table)". The cursor
  starts on it only for a hive table or one schema, and on the first row
  inside otherwise. The row hides while a filter is typed, and is absent
  when nothing inside is openable. Inside a directory, the last row
  counts the files with no reader; Enter on it shows them, labeled
  binary, and Enter on one of those shows its bytes in the hex view. A SQLite
  database's label counts its tables ("3 tables"); one of several lists
  them inside, a row each, and Enter opens one. A file a spec reads as
  several variants opens whole on Enter; → lists its variants, and Enter
  on one opens it alone. The Notes tab says what a
  read had to decide. In a collection, "dataset" marks a remote directory
  not listed until you enter it, and "missing" a local path with nothing
  there.
  A file row that is not read lazily says how opening it reads it, dim
  beside its name: "converts" (read once into a temporary file), "in
  memory" (read whole), or "downloads" (a remote file copied first).
  The details pane shows a local file's first rows under ROWS, read when
  the row is selected; Enter opens the file on those same rows, so they
  are read once. Without the pane, they take the free lines at the bottom
  of the screen. [data] preview_max_mb sets the largest file read.

Help and leaving:
  ? / F1:           This help (? before typing starts; F1 always)
  Ctrl+Q / Ctrl+C:  Quit

What datui remembers, all under its cache directory and never the data
itself: recent paths and how often each was opened, the shapes and column
names it measured (so this screen can say 1,000 × 11 without reading
anything), query history, section folds, remembered directories, bucket
listings and hidden cloud sources. datui --clear-cache removes all of it.
