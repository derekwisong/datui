Templates save a query, filters, sort and column layout, and apply them to
datasets that match by path or schema.

Template list:
  ↑ / ↓ (j/k):      Move in the list
  Enter:            Apply the selected template
  s:                Create a template from the current state
  e:                Edit the selected template
  d:                Delete the selected template, after confirming
  ? / F1:           Show this help (F1 works in text fields)
  Esc:              Close

  The Score column marks how well each template fits the open dataset, and
  the active template carries a check mark. T at the table applies the most
  relevant template without opening this menu.

Create and edit form:
  Tab / Shift+Tab:  Move between fields
  Enter:            Save
  Esc:              Back to the list

  Name is required. The match fields are optional: exact path, relative
  path, path pattern and filename pattern (glob-like), and schema match
  (column names).

Matching:
  Templates are scored in this order: exact path, relative path, path and
  filename patterns, schema columns, then generic templates.

Delete confirmation:
  Tab or ← / →:     Switch Cancel / Delete (Cancel is selected first)
  Enter:            The selected button
  D:                Delete immediately
  Esc:              Cancel
