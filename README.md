# Demo dataset curation: issue chart assets

The 14 PNG files are unchanged analytical previews from the public demo dataset report prepared September 28, 2026. They were rendered with Matplotlib from frozen public-data results; they are not datui screenshots or native chart exports.

The associated GitHub issue provides dataset scopes, source credits, verification status, and the implementation plan. This branch stores issue illustrations only and is not intended to merge into the application branch.

Sources: BTS Reporting Carrier On-Time Performance; SSA published baby-name data; NOAA GHCN-D; OpenFootball (CC0); NYC TLC; USGS; GCAT (J. McDowell, planet4589.org/space/gcat, Release 1.8.8, CC BY 4.0; derived orbital-attempt/year subset); Palmer Penguins (Horst, Hill & Gorman, 2020, doi:10.5281/zenodo.3960218, CC0).
