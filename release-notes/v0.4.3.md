## What's changed

- The Python module works with Python Polars 2.0: DataFrames go in as Arrow data, and `capture=True` returns the view's rows there, with a warning, since 2.0 cannot read the plans datui writes
- A `[limits]` config section raises every cap a file can hit: records indexed in one pass (flight logs, candump, text-file lines, format specs), ELF symbols, MIDI files and events, journal JSON, SDF fields, VCD signals, FIX tags and fields, GPX extension fields, NumPy headers and the rows of an Info list; each note or error that hits one names its key
- With `--follow`, a file replaced right as it is opened is read again instead of followed as the file it replaced
- Sizes are shown the same way everywhere, in binary units
- Chart exports tick and title their axes like the chart on screen: Y axes end on a tick, log axes tick on powers of ten, dates fall on the calendar, and histogram and density axes read Count, Share or Density
- Value counts and Data Quality shares show small shares precisely, such as `0.04%` or `<0.01%`, instead of rounding them to `<0.1%` or `0.00%`
- Esc closes the overlay on top, and going home closes every overlay so none comes back over the next dataset
- Footer keys say what the help says: Data Quality's keys read in the same words and sentence case as every other screen (`v Sample rows`, `b Baseline`, `Enter Details`), Sort & Filter's `L` says Freeze, and keys no help listed (questions, the crosshair, Data Quality's forms and popups) are in the help and the reference
- Started in a huge directory, the home screen shows its first rows and `… N more` (Enter shows them all), so the cloud and example sections stay in view; every directory section starts with `..`, which goes up a level
- Combine's name is a full text field, edited with the same keys as every other
- In a picker, Space types a space once you have typed, so a name of several words narrows instead of choosing its first match; Enter chooses
- With `display.unicode = never`, no screen draws a Unicode middle dot or ellipsis, and wide characters no longer push sidebars and section rules out of line
- Filtering on the home screen and drawing the table allocate far less, and a sidebar Apply reads the data once
- `performance.threads` caps the threads Polars computes with (0, the default, uses every core); `POLARS_MAX_THREADS` still wins when set
