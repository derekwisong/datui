## What's changed

### The interface overhaul

The whole surface was rebuilt on one component kit over #313-#320: one border per dialog, keys as chips in a footer instead of buttons, one accent for focus, type-to-narrow pickers instead of arrow-cycled lists, and every screen legible in plain ASCII terminals. Enter applies and Esc discards, everywhere. The entries below carry the details per screen.

- A finished export says so in one line on the bottom bar, gone on the next key; nothing to dismiss (#336)
- Error and confirmation dialogs match the rest of the UI: the message and the keys, no buttons (#336)
- Enter on an incomplete pivot or melt highlights what is missing in the form instead of raising an error (#336)
- The bottom bar's count reads `1,000 rows`, abbreviating large totals like the home screen (`417,321 of 1.2M`); a pivoted or melted view carries a chip saying so, and `R` takes it away (#336)
- Ctrl+W and Ctrl+U edit a picker's search text; chords no longer type their letters there or in the view save form (#336)
- End jumps to the bottom of a help screen (#337)


### Home screen

- Run `datui` with no path: recent datasets, the current directory, your data directories and cloud sources, with rows, columns and size before you open anything (#145, #280, #285)
- Type to filter by name or column name; Ctrl+O returns here from anywhere
- Directory labels say what is inside (`12 parquet`, `mixed`, `delta`) (#243, #272, #278)
- → goes inside any directory; its `(all files)` row opens the whole directory as one table (#279, #286)
- Ctrl+D keeps a directory listed on the home screen without editing the config; press it again to forget
- `datui <directory>` opens a directory with no `--hive` flag (#286, #288)
- Files datui cannot read are hidden; Ctrl+A shows them, dimmed (#296)

### Directories of files

- A directory opens as one table when its files' columns fit the widest file's, for Parquet, CSV and NDJSON (#234, #284, #287)
- Files that disagree are read as the union of their columns, and the Info panel's Notes tab says what was found (#197, #204, #209)
- Delta, Iceberg and Hudi tables are labelled, not read as plain Parquet (#243)
- Exports can add a column naming each row's source file (#205)

### Cloud

- A CLOUD section with one row per store: S3 and S3-compatible servers, AWS profiles, Google Cloud, Azure Blob Storage, MinIO and s3cmd, found from the logins you already have (#181, #182, #183, #185, #187, #188)
- `[[cloud.sources]]` adds stores, with secrets kept in the environment or a password manager, never the config (#181, #189)
- Built-in public datasets (NOAA, OpenAlex, Overture Maps and more) open with no login (#186, #203)
- Sources are listed when you enter them; `[cloud] discover` chooses which logins become sources (#293)
- `datui gs://bucket/dir/` reads a directory of CSV or JSON Lines in place, and `~` takes cloud URLs (#296)
- Remote Parquet reads one row group at a time, and many-file datasets read only the files a page needs (#163, #191, #218)

### Data quality

- Data Quality reports what is wrong with a dataset in plain words: problems ranked above notes, missing values said once with each column's rate, the clean columns named with the checks they passed, and every finding's rows one Enter away, a sample's included; it reads the same sample as every other analysis tool, and profiles run by file, partition, row chunk or time window (#244, #269)

### Analysis on large tables

- Describe, Distribution and Correlation analyze a 100,000-row sample of a larger table, spread across all of it: a few dozen row groups of one Parquet file, or one streamed pass over anything else that holds only the sample. 37 million rows of NOAA weather data in S3 take seconds
- One sample serves every analysis tool, Data Quality included: `s` chooses the rows (a partition, a list or range of them, files, a time range), the method (random, equal per value, first rows, every row), the size and the seed; the first run on a dataset starts from the form and later tools reuse its sample, and `v` shows the sample's rows in the table viewer
- The title says what was read (`sample of 100,000 of 36,839,175 rows`); `r` draws another sample and `a` reads every row
- Esc cancels a run in progress, and the progress shows elapsed time instead of a bar that could not move
- The Q-Q plot rises with the data instead of folding over at the median, the normality p-value beside it is a real one, and the histogram's bars line up with its axis
- Distribution p-values are calibrated: each family is fitted once, tested by Kolmogorov-Smirnov against 199 samples drawn from the fit and refitted, and drawn in the Q-Q plot and histogram with the same parameters; a family that cannot describe a column says why instead of ranking a placeholder score
- Distribution fitting names a column only when a distribution fits it: `Constant` for one value, `No clear fit` when every candidate is rejected, and the simpler family when two fit alike
- `[performance] analysis_sample_rows` (and `--sample-rows`) replaces `sampling_threshold`, which is no longer read; 0 reads every row

### Copy to the clipboard

- `y` copies from the table: the current cell, the current row, the rows on screen, or the whole view as queried, filtered and sorted (#310)
- Formats: TSV (what a spreadsheet expects from a paste), CSV, or an aligned Markdown table; TSV and CSV copies also carry an HTML table flavor, so a paste into a spreadsheet or an email keeps its columns (#310)
- Works locally through the display server and over SSH through OSC 52; `[clipboard] backend` chooses, `auto` picks for you (#310)

### Also

- New look: Tokyo Night palette, typed column headers, a tinted current row (#125)
- The export dialog is one compact form — no inner boxes or buttons: Enter exports from anywhere, Space toggles, Esc cancels (#313)
- Every column of a multi-sort runs its own way: Space cycles a column none → ascending → descending, the header marks each column's direction, and r reverses them all (#314)
- The Sort & Filter sidebar is two flat lists — Columns and Filters — with no inner boxes or buttons: Enter applies, Esc cancels, and filters are edited on their row through type-to-narrow pickers instead of arrow-cycling the column list (#314)
- Pivot & Melt is one form that echoes its spec — `department × job_title → avg(salary)` — live above the footer: each field opens a picker scoped to that field alone (no more one filter box silently emptying the other lists), the aggregation is a short list instead of an arrow grid, and Enter applies from anywhere (#315)
- The chart type switches from anywhere: 1-5 name a tab and [ ] cycle, the options sidebar is one compact form showing only the active type's options with columns picked through type-to-narrow pickers, and the chart export dialog loses its inner boxes and buttons (#316)
- Templates are now views, on v and V: the list says why each view matches the open file (same file, same columns, a pattern), and saving is a name-first form with the matching rules folded under one section (#317)
- A new view is named after the file, or the query's first words, instead of template0001 (#317)
- Saving a view needs something to save: on an untouched table, s refuses instead of minting an empty view that would shadow real ones in auto-apply (#317)
- Editing a view you have not applied changes its name, description and matching without overwriting its saved settings with the table's current state (#317)
- q returns to the home screen when the dataset was opened from it, and quits as before when datui was launched straight onto a file; Q and Ctrl+Q always quit, and the control bar says which meaning q carries (#320)
- One selection and tab style everywhere: the active tab carries the accent in the query strip and the Info panel too, and every selection tint comes from the theme (#319)
- The help overlay wraps at word boundaries, says Esc closes it, and caps its line length on wide terminals (#319)
- PgUp/PgDn on the home screen move a screenful, like the table, instead of ten rows (#319)
- Keys typed while busy are queued instead of dropped (#162)
- Paging loads the next rows in the background, so a page never shows half empty (#299)
- H reads a CSV's first row as data, for files with no header row (#306)
- `?` opens help on the home screen too, and every screen's control bar and help follow one format (#307)
- `--help` and the man page group the options and end with examples; boolean flags work bare — `datui --no-header data.csv`, and `--no-header=false` for the opposite (the old `--no-header true` spelling no longer parses) (#307)
- Every symbol in the interface has an ASCII twin, so a terminal without UTF-8 gets readable chrome instead of boxes (#307)
- Every symbol now also exists in the common coding fonts: the cloud and network marks, the checkboxes and the half dots used characters JetBrainsMono Nerd Font does not carry, which fell back to an emoji or CJK font and rendered blank or clipped (#325)
- A `[glyphs]` config section replaces any symbol for fonts that carry more than the tested floor — the cloud mark back, a quarter-circle spinner, Nerd Font icons — checked at startup so a wrong slot or width is a named error, not a broken screen (#325)
- The font-coverage audit is a script in the repo (`scripts/code/audit_glyphs.py`), so the default symbol set is tested against real font tables instead of folklore (#325)
- A new wordmark on the home screen, drawn in light box characters every floor font carries — the old heavy strokes needed a font fallback on Liberation Mono systems
- Views only apply when one of their rules fits the file: V opens the list instead when nothing matches, and a new view matches by schema by default, so it carries to the next table shaped the same (#307)
- `--template NAME` and `[templates] auto_apply` now do what they say; both were parsed and ignored (#307)
- Unaliased aggregates name their result `fn_column`, so `select avg salary, max salary by department` no longer errors with a duplicate column, and `/` divides alongside q-style `%` (#307)
- The row count reads "Rows: 417 of 1,000" while a filter, query or drill-down narrows the view (#307)
- The export format follows a typed extension, so naming the file `out.csv` no longer writes Parquet bytes into a `.csv` (#307)
- Enter on a correlation matrix cell shows the pair's coefficient, R², p-value and pairs used, instead of a blank screen (#307)
- Filtering by a column name now also finds datasets below the working directory, as the docs always said (#307)
- The Info panel's Schema tab says per column how many files carry it, and ←/→ switch its tabs from anywhere (#307)
- A misplaced or repeated clause keyword, or anything left over after a query expression, is an error naming the token instead of being silently ignored (#311)
- Sorted columns carry a direction mark in the header, so a sorted view — and `r` reversing it — is visible at a glance (#311)
- Reopening `/` restores the last query selected, so typing states a new question instead of appending to the old one (#311)
- While a dataset has unread notes, `i` opens the Info panel on the Notes tab (#311)
- The home screen no longer repeats a recent that the current directory's section already lists, and a directory of mixed formats says what it passed over once, not twice (#311)
- The home screen's wordmark steps aside on short or narrow terminals, giving the rows and the path the room (#311)
- `--delimiter` sets how a file is read; per-file layout keys are no longer read from config (#291)
- Python: `datui.view(lf, capture=True)` returns what you built in the TUI — query, filters, sort, reshape — as a LazyFrame to keep working with (#308)
- Python: works with `polars` 1.38 and later (#164, #171)
- Polars 0.55, Rust 1.95, Linux arm64 builds, rewritten docs (#148, #150, #164, #167)
- Overwriting a file asks first, starting on No, and declining returns to the filled export form instead of throwing the path away
- Sidebars cap their share of the width, so the table never disappears behind Sort & Filter, Views, Info or Pivot & Melt
- The export path, format and compression stay in sync both ways: typing `out.csv.gz` selects CSV and gzip, and picking a format rewrites the typed extension to match
- Enter on a blank export path says "Enter a file path." in the form instead of doing nothing
- A whole-table copy whose size is not known yet asks before collecting
- The loading screen keeps `^O`, `q` and `?` visible beside the progress and they act at once, and abandoning a cloud load stops its reads instead of letting them run on
- Long error and confirmation messages scroll inside their dialog instead of running off the screen
- A terminal without UTF-8 gets every border and help screen in ASCII, not just the symbols

### Fixed

- Counting a dataset whose files disagree on a column type no longer crashes (#201, #202)
- Opening a dataset while its row count runs no longer hangs (#245, #251)
- An unresponsive network share no longer freezes the interface (#265)
- Sidebar filters keep the running query, and charts no longer freeze the screen (#154)
- The bucket list honors `AWS_ENDPOINT_URL` and `--s3-endpoint-url` (#158)
- Nulls sort last in both directions (#130)
- Help opened on the home screen with F1 could not be closed (#307)
- Sort & Filter edits made and then canceled no longer resurface pre-staged the next time the sidebar opens (#307)
- `datui --clear-cache` now clears the whole cache; it left measurements, histories and hidden cloud sources behind, which also broke the documented way to unhide a source (#307)
- A wrong `--sheet` names the sheets the Excel file has (#307)
- A `~` or `$VAR` typed in the export dialogs expands as it does everywhere else a path is typed, instead of failing with "No such file or directory" (#316)
- The warning mark used a character Liberation Mono and Noto Sans Mono route to the color-emoji font; it is now the caution triangle every floor font carries (#325)
- The Info, data-quality and analysis panels drew their separators, placeholders and R² from literal Unicode, garbling them in a terminal without UTF-8; they follow the ASCII fallback like everything else (#335)
- Text under the cursor block picks black or white by the cursor color's luminance — a dark themed cursor no longer hides its character — and a `cursor_text` color slot overrides the choice (#335)
- Ctrl+C no longer quits — and `?` no longer opens help — while typing a Data Quality scope; the scope input is an ordinary text field
- A letter with Ctrl or Alt held no longer triggers table features: Ctrl+E opened Export, Ctrl+R reversed the sort, and so on
