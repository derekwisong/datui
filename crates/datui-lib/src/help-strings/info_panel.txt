Dataset technical info. While a dataset has unread notes, i opens this
panel on the Notes tab; after that, on Model for a model file, on Audio for
an audio file, on MIDI for a MIDI file, on VCD for a value change dump, and
on Schema for anything else.

  Tab / Shift+Tab:  On Schema tab: move focus (tab bar ↔ schema table).
                    On other tabs: focus stays on tab bar.
  ← / → (h/l):      Switch tabs. Afterward focus rests on the tab bar, so
                    Tab returns to the body before ↑/↓ scroll
  ↑ / ↓ (j/k):      Schema tab (when focused) or Notes tab: move the cursor.
                    Model, Audio, MIDI, Metadata and format tabs: scroll
                    the list
  PgUp / PgDn:      Model, Audio, MIDI, Metadata and format tabs: scroll
                    the list a page
  Home / End:       Model, Audio, MIDI, Metadata and format tabs: the top
                    or the end of the list
  Enter:            Notes tab: take the offer on the note, where it has one
  ? / F1:           Show this help
  Esc / i:          Close info panel

  The panel's footer names the keys that work now, and when the schema
  table is taller than the panel it counts the columns out of view. The
  rail marks focus: beside the active tab, or on the schema's current row.

Tabs:
  Schema:      Every column, its type, and which footers the schema came from.
               A column's unit too, when a delimited format spec read a unit row
               or the file names one (DataFlash, a DBC dictionary). For a
               dataset a collection lists with a codebook, what each column
               means (About), and below, the selected column's note and codes
  Model:       A SafeTensors or GGUF file's parameter count, size, dtype or
               quantization mix, and its header metadata, each value whole up
               to 64 KiB. Only for model files
  Audio:       A WAV, BWF, RF64 or AIFF file's channels, sample rate, sample
               format, frames and length; its Broadcast WAV, iXML and info
               fields; and its markers. Only for audio files
  MIDI:        A MIDI file's format, timing, length, tempo, meter and key,
               and each track's name, events, notes and channels. Only for
               MIDI files
  Metadata:    The key="value" pairs of the metadata line a delimited format
               spec names; a line that is not pairs is shown as it is. Only
               for files read through such a spec
  VCD:         A value change dump's timescale, date, version, value changes
               and time span, and each signal's type, width and identifier.
               Only for VCD files
  FIX:         A FIX log's messages per BeginString, the dictionaries read
               with it, and each column's tag number and the names the
               dictionaries give it. Only for FIX logs
  SDF:         An SDF file's records, and each data field's type and how many
               records hold it. Only for SDF files
  NumPy:       A NumPy array's shape, type, order and format version, and
               each field's type and offset. Only for NumPy arrays
  ELF:         An ELF file's class, machine, type, entry point, the bytes in
               flash and in RAM, and each section. Only for ELF files
  ULog:        A ULog's version, topics and dropouts, its info messages and
               each parameter's starting value. Only for ULog files
  DataFlash:   A DataFlash log's message types, each with its records,
               format and length. Only for DataFlash logs
  CAN:         A candump log's frames and interfaces, the dictionaries read
               with it, and each message's id, frames and signals. Only for
               CAN logs
  Parquet:     A Parquet file's row groups, compression and writer, and each
               column's least and greatest value and nulls from its footer.
               Read when the panel first opens. Only for one Parquet file
  Arrow, Avro, ORC:
               The record batches, record or stripes, codec and metadata at
               an end of the file. Read when the panel first opens
  Excel:       A workbook's worksheets, each with its range and size, and which
               one is open. Only for Excel files
  SQLite:      A database's page size, versions and tables, with their
               columns and the rows ANALYZE stored. Only for SQLite tables
  GPS:         What an NMEA log or GPX file holds: rows, sentences or points,
               the time span and the bounds. Only for GPS logs
  Resources:   What the data costs to hold and to read, and how it is read:
               lazy, converted once, or in memory
  Partitions:  The layout of a partitioned dataset. Only when it has one
  Notes:       What datui noticed about the data while reading it. Only when
               there is something to say

Notes:
  A note is an observation, not a fault: a column that is not in every file,
  files that disagree on a type, a file with no rows in it, row groups big
  enough that a page of rows costs much more than a page, so many small files
  that opening them for their footers is a job of its own, directories that do
  not all partition by the same keys, a file whose footer could not be read.
  Each one says what it is based on, so "in 1 of 3 files" never stands for files
  datui has not looked at. None of them costs a read of its own.

  A note is one sentence and the line beneath it saying what it is based on.
  When the list is taller than the panel, the corner says how many are out of
  view, unless the note the cursor is on fills the panel and needs that row
  itself. Whole notes only, so a claim never appears without its basis, nor a
  basis without its claim. Where the note the cursor is on will not fit at all,
  the panel says so; a shorter one may still fit.

  A note about a column the files store in more than one type offers to read it
  as text. Press Enter on it and the column is read from the files that disagree
  too, at the type each of them wrote, so the values the conflict hid can be
  seen; the marks and the note go with the conflict. Nothing is listed again and
  no footer is read again. A filter or sort on the column then compares text,
  and a note says so. A column any file holds as a list, an array, a duration,
  binary or an unknown type has no text form datui can show, and is not
  offered.

  When there is something to note, the i key in the control bar takes a quiet
  accent until this panel has been opened. display.notes_accent = false turns
  that off; the notes are still collected and this tab still appears.
