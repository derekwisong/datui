# Theming from Your System

Datui can follow a theme generated by something else on your machine, such as
a desktop theme manager, chezmoi, home-manager or a dotfiles repo. Point
[`import`](configuration.md#importing-other-config-files) at the file it
generates and datui merges it in below your own settings.

## Light and dark

```toml
[theme]
mode = "auto"   # "auto" (default), "dark", or "light"
```

`auto` reads `COLORFGBG` and falls back to `dark`. Alacritty, Kitty and Ghostty
do not set that variable, so on a light color scheme in those terminals set
`mode = "light"`, or the header and row stripes come out near-black.

## Omarchy

[Omarchy](https://omarchy.org/) renders per-app theme files from templates when
you switch themes. Datui ships one.

1. Install the template from the repository:

   ```bash
   mkdir -p ~/.config/omarchy/themed
   cp contrib/omarchy/datui.toml.tpl ~/.config/omarchy/themed/
   ```

2. Import the file Omarchy generates:

   ```toml
   # ~/.config/datui/config.toml
   import = ["~/.local/state/omarchy/current/theme/datui.toml"]
   ```

3. Switch themes as usual:

   ```bash
   omarchy theme set tokyo-night
   ```

The template sets `theme.mode` from the theme's polarity and maps its accent
onto datui's accent, gradient and selection tint. A running datui keeps the
theme it started with; the next launch picks up the new one.

### Overriding a color everywhere

Your own `config.toml` wins over anything imported:

```toml
import = ["~/.local/state/omarchy/current/theme/datui.toml"]

[theme.colors]
int_col = "#ff8800"
```

One catch: a color set to exactly datui's built-in default reads as unset and
will not override the import. See
[the caveat](configuration.md#a-caveat-when-overriding-an-imported-color).

### Overriding one theme only

Import a second file that only some themes provide:

```toml
# ~/.config/datui/config.toml
import = [
  "~/.local/state/omarchy/current/theme/datui.toml",
  "~/.local/state/omarchy/current/theme/datui.override.toml",
]
```

```toml
# ~/.config/omarchy/themes/osaka-jade/datui.override.toml
[theme.colors]
int_col   = "#ff8800"
float_col = "#ff00ff"
```

Omarchy copies your theme directory into place before rendering templates, so
the override arrives untouched. Themes without the file are skipped with a
warning on stderr.

Name it `datui.override.toml`. A file named `datui.toml` **replaces** the
generated file and drops every color it does not restate.

## Other systems

Only the paths above are Omarchy-specific. Any generator that can write a TOML
file in datui's config format works the same way:

```toml
import = ["~/.local/share/mytheme/datui.toml"]
```

The imported file may set any section, not just `[theme.colors]`.
