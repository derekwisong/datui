Read a binary file with another format spec.

  (type):           Narrow the list to the names that contain it
  ↑ / ↓:            Move
  Enter:            Read the file again with the spec chosen. The query,
                    filters and sort are cleared
  Backspace:        Delete a character (Ctrl+W a word, Ctrl+U all)
  Esc:              Close and keep the format
  F1:               Show this help

The list starts with the spec the file was read with, then the others
that matched it the same way, then every other spec on the search path
for a file (or for a directory of column files). `datui formats` lists
them and where each came from.
